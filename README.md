# gebaeudeserviceboehme.de

Veröffentlichte Website von Gebäudeservice Böhme (Kevelaer, Duisburg, Düsseldorf) über GitHub Pages.

Die Dateien hier sind erzeugt. Nicht direkt bearbeiten: Texte und Einstellungen liegen in `larsboehme/trading-bot`, Ordner `website/` (`inhalte.py`, `build.py`). Dort `python3 paket.py` ausführen und den Inhalt von `website/dist/` hierher übernehmen.

- Custom Domain: `CNAME` (gebaeudeserviceboehme.de)
- `.nojekyll`: Dateien werden ohne Jekyll ausgeliefert
